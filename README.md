# Dynamic-clock-gating-on-RISC-architecture-
This project implements dynamic clock gating on RISC architecture in order to reduce power consumption. 
#Features
-clock gating for idle modules. 
-reduced swtiching activity 
-power optimization. 
#Tools used 
-Vivado
#results 
-power reduced by 12.75%
-verified using power analyzer tool.
#How to run 
- compile using vivado.
- give constaints in xdc file.
- synthesize the code.
- view waveform and power report.

-attach waveforms + power report.
